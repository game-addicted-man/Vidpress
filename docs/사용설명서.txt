VidPress — 동영상 용량 줄이기 · 형식 바꾸기
===========================================

HandBrake처럼 동영상 용량을 줄이거나 다른 형식으로 바꾸는 Windows 프로그램입니다.
인터넷 연결 없이 내 컴퓨터 안에서만 동작하며, 원본 파일은 절대 바꾸지 않습니다.


■ 설치하기

  VidPress-Setup-(버전).exe 를 실행하고 [다음] → [설치] 를 누르면 됩니다.
  관리자 권한 없이 설치되며, 시작 메뉴와 바탕화면에 VidPress 아이콘이 생깁니다.

  ※ "Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] → [실행] 을 누르세요.
     (전자 서명이 없는 프로그램이라 처음 한 번 나오는 경고입니다.)
  ※ 설치 중 '보내기 메뉴에 추가' 를 선택하면, 탐색기에서 동영상을 오른쪽 클릭 →
     [보내기] → [VidPress] 로 바로 열 수 있습니다.
  ※ 지우기: Windows [설정] → [앱] → [설치된 앱] 에서 VidPress → [제거].

  설치 없이 쓰려면: VidPress.exe 와 ffmpeg 폴더를 같은 폴더에 두고 VidPress.exe 를
  실행하면 됩니다.


■ 사용 방법 (4단계)

  1) 파일 넣기   : 동영상을 창 안으로 끌어다 놓거나 [＋ 파일 추가…] / [폴더 추가…] 를 누릅니다.
                   여러 개를 한꺼번에 넣을 수 있습니다.
  2) 프리셋 고르기: 용도에 맞는 프리셋을 고릅니다. 잘 모르겠으면 "추천" 그대로 두세요.
  3) 저장 위치   : 기본은 원본과 같은 폴더에 "이름_변환.mp4" 로 저장됩니다.
  4) [▶ 변환 시작] 을 누릅니다. 끝나면 저장 폴더가 열립니다.


■ 프리셋 (용도)

  추천 — 화질은 그대로, 용량만 줄이기 : MP4(H.264). 어디서나 재생. 보통 30~70% 줄어듭니다.
  더 작게 — H.265로 크게 줄이기       : 같은 화질에 H.264보다 30~50% 더 작습니다.
  최대 압축 — 720p + H.265             : 해상도를 720p로 낮춰 용량을 가장 작게 만듭니다.
  메신저·카톡 전송용 — 720p H.264      : 카카오톡·문자·메일로 보내기 좋은 크기.
  고화질 보관용 — 화질 우선 (H.265)    : 화질 손실을 거의 느낄 수 없게 압축 (시간이 더 걸림).
  목표 용량 맞추기                     : "50MB 이하" 처럼 원하는 용량 이하로 맞춥니다.
  형식만 바꾸기 — 재압축 없이 빠르게   : 예) MKV → MP4. 화질 손실 0, 몇 초면 끝납니다.
  소리만 추출 — MP3                    : 동영상에서 소리만 MP3 로 저장합니다.

  세부 설정을 직접 바꾸면 프리셋이 자동으로 "사용자 지정" 으로 바뀝니다.


■ 세부 설정

  방식        : 화질 기준 / 목표 용량 / 형식만 바꾸기 / 소리만 추출
  출력 형식   : MP4(H.264·H.265·AV1), MKV, WebM(VP9), MOV, AVI, TS / MP3, M4A, WAV, FLAC
  화질        : 오른쪽(고화질)으로 갈수록 화질이 좋고 용량이 커집니다. 23 이 기본값입니다.
  해상도      : 영상 크기를 줄입니다 (커지게 하지는 않습니다). 세로 영상도 알아서 맞춥니다.
  목표 용량   : 파일 하나당 이 용량(MB) 이하가 되도록 합니다.
                "필요하면 해상도 자동 조정" 을 켜 두면 용량이 너무 작을 때 해상도를 낮춰
                화면이 깨져 보이지 않게 합니다.
  인코딩 속도 : 천천히 할수록 같은 화질에 용량이 조금 더 작아집니다.
  소리        : 소리 음질(비트레이트), 원본 그대로, 또는 소리 제거.
  프레임      : 60/30/24fps 이하로 제한해 용량을 줄입니다 (원본보다 높이지는 않습니다).
  하드웨어 가속: NVIDIA·Intel·AMD 그래픽카드가 있으면 훨씬 빠르게 변환합니다.
                (자동으로 확인해서 되는 경우에만 켤 수 있습니다. 실패하면 알아서 CPU로 다시 합니다.)
  HDR 색 보정 : 아이폰 HDR 같은 영상이 일반 화면에서 색이 바래 보이지 않게 바꿉니다.
  자막 유지   : 원본에 들어 있는 자막 트랙을 함께 넣습니다.


■ 알아두면 좋은 것

  · 목록에서 파일을 더블클릭하면: 완료된 파일은 결과 파일 위치가, 실패한 파일은 이유가 나옵니다.
  · 목록에서 오른쪽 클릭: 위치 열기, 다시 변환하기, 오류 보기, 목록에서 삭제.
  · 변환 중에도 파일을 더 끌어다 놓을 수 있습니다. 순서대로 이어서 변환합니다.
  · [■ 중지] 를 누르면 지금 변환 중인 파일만 지우고 멈춥니다 (완료된 파일은 남습니다).
  · 같은 이름의 파일이 이미 있으면 덮어쓰지 않고 "(2)", "(3)" 을 붙입니다.
  · 변환하는 동안 컴퓨터가 절전 모드로 들어가지 않습니다.
  · 설정은 자동 저장되어 다음에 그대로 열립니다.
  · 작업 기록 파일: %APPDATA%\VidPress\VidPress.log  (문제가 생겼을 때 확인용)


■ 문제 해결

  "FFmpeg를 찾을 수 없습니다"  → VidPress.exe 옆에 ffmpeg 폴더(ffmpeg.exe, ffprobe.exe, dll 파일들)가
                                 있는지 확인하세요. 설치 파일로 다시 설치하면 해결됩니다.
  백신이 실행을 막는 경우      → 서명 없는 프로그램이라 생길 수 있습니다. 예외로 등록하세요.
  특정 파일만 실패하는 경우    → 더블클릭해서 이유를 보고, "추천" 프리셋이나 MKV 형식으로 다시 해 보세요.
